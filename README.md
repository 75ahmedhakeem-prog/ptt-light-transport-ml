# Light-transport models and ML surrogate for plasmonic photothermal planning

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23530112.svg)](https://doi.org/10.5281/zenodo.23530112)

Code and data for the article *"Which light-transport model is needed for plasmonic photothermal planning?
An experimentally anchored comparison and a machine-learning surrogate for NIR-I/NIR-II thermal-dose design"*
(A.M. Abdel Hakeem, S.A. Ahmed, submitted 2026).

The repository contains

* Gans-theory optics of gold nanorods with the analytic dielectric function of gold (`gans.py`);
* three light-transport models: corrected and published Beer–Lambert sources, the δP1 (δ-Eddington diffusion)
  model solved by finite volumes (`dp1.py`) and a vectorised Monte Carlo code with Fresnel boundaries,
  Henyey–Greenstein scattering and delta (Woodcock) tracking (`mc.py`, `mc_het.py`);
* an axisymmetric finite-volume Pennes bioheat solver with CEM43 thermal dose (`heat.py`, `heat2.py`);
* calibration and blind tests against three published experiments;
* the 422,304-sample δP1 design dataset, ANN and XGBoost surrogates with the level hold-out test,
  treatability maps under the ANSI skin MPE and the verified protocol design.

## Installation

```
python -m pip install -r requirements.txt
gunzip -k data/design_dataset_valid.csv.gz
```
Python ≥ 3.10. All scripts are run from the `code/` folder (`cd code`); they read and write `../data/` and `../figs/`.

## Data

| File | Content | Source |
|---|---|---|
| `pratap_fig2_absorbance.csv` | Absorbance spectra of the nanorod samples | digitised from Pratap et al., ACS Appl. Nano Mater. (2024), doi:10.1021/acsanm.3c04750 |
| `pratap_fig56_dT.csv`, `pratap_fig4_plaingel_dT.csv` | Temperature rise at 1, 5, 10, 15 mm (loaded phantoms and plain gel) | same, vector digitisation (±0.05 °C) |
| `pratap_fig8_raw.csv` | IAD absorption and scattering coefficients | same, raster digitisation |
| `shaw_fig4_TE.csv` | Thermocouple temperatures of the subsurface phantoms | digitised from Shaw et al., Phys. Eng. Sci. Med. 47 (2024) 1107, doi:10.1007/s13246-024-01433-w (±0.2 °C) |
| `design_dataset_valid.csv.gz` | 422,304 δP1 + Pennes samples (inputs: λ, spot, μa,GNR, depth, diameter, perfusion, h, irradiance, time; outputs: coverage, T_skin,max, T_tum,min, T_tum,max, collateral volume) | generated by `gen_dataset.py` |
| `sens_nir2_extra.csv` | Extra 1064 nm runs at μa,GNR = 0.01 and 0.02 mm⁻¹ | `sens_nir2.py` |
| `*.json`, `*.pkl`, `colab_res/`, `ml_local/` | Intermediate and final results of every stage | the scripts below |

The digitising scripts (`digitize_*.py`) need the original article figures, which are not redistributed;
the digitised CSV files are provided instead. Please cite the original articles when using them.

## Reproducing the results

| Step | Script | Output |
|---|---|---|
| Nanorod optics (Fig. 2, Table 3) | `make_fig_ptt.py` (uses `gans.py`) | `stageA_mua.csv`, figs 1–3 |
| MC verification and heat partition (Tables 4–5, Fig. 4) | `stageB_phantom.py`, `stageB_dp1.py`, `make_fig_ptt2.py` | `stageB_summary.json` |
| Calibration and blind test on dataset 1 (Table 6, Fig. 5) | `stageC_fit.py`, `stageCD_excess.py`, `stageC_uncert.py` | `stageCD_excess.json` |
| Blind test on dataset 3 (Table 7, Fig. 6) | `stageD_shaw.py` | `stageD_shaw.json` |
| δP1 versus MC (Table 8, Fig. 7) | `stageBD_dp1_compare.py`, `make_fig7.py` | `stage_dp1_compare.json` |
| Design dataset (Table 2) | `gen_dataset.py` (≈ 20 min on 2 cores) | `design_dataset.csv` |
| Surrogates, level hold-out (Table 9, Fig. 8) | `ml_design.py`, `ann_ensemble.py`, `../colab/xgb_tune.py`, `make_fig89.py` | `colab_res/`, `xgb_tuned/`, `ann_ensemble_holdout.csv` |
| Treatability and NIR-II sensitivity (Figs. 9–10) | `treatability.py`, `sens_nir2.py`, `sens_nir2_coll.py`, `make_fig89.py`, `make_fig10.py` | `treatability_grid.json`, `sens_nir2*.json` |
| Protocol design and verification (Table 10) | `design_opt.py`, `design_uncert.py` | `design_opt.json` |

XGBoost was run in Google Colab; see `colab/RUN_ML_IN_COLAB.md` and `colab/RUN_IN_COLAB.md`.
